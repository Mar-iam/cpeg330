# CPEG 330 — Interactive Course Materials
 
Interactive visualizations for **CPEG 330: Data Structures** at Hamad Bin Khalifa University, by Dr. Mariam Bahameish.
 
**Live site: https://mariam.qa/cpeg330/**
 
- **Sorting** — bubble, selection and insertion sort; merge and quick sort; counting and radix sort
- **Trees** — the four AVL rotation cases, and an AVL rotation game for class
- **Hashing** — chaining, linear probing and double hashing, with a live load factor
- **Graphs** — BFS, DFS, cycle detection and Dijkstra
Every page runs in the browser, with nothing to install. All have the same controls (Reset, Prev, Next, Auto) and keyboard shortcuts: `→` next, `←` back, `Space` auto, `R` reset. Two buttons at the bottom right turn on **Predict mode**, which pauses and asks the class what happens next, and **Projector mode** for large rooms.
 
To run it locally, open `index.html` in a browser, keeping the `pages` folder beside it. Each file in `pages/` is a self-contained page.
